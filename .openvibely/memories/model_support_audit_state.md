The latest successful bounded model-support audit uses `2026-08-31` as the prior-success cutoff, documented by OpenVibely issue `#974`. It found no actionable post-cutoff support proposal: Anthropic Fable 5.1/Mythos 5.1 and OpenAI GPT-6 Astra are already supported; voice-only releases such as OpenAI GPT-Live-1 are outside the current text/image Task and Chat provider contract; and Z.AI GLM-5.3-Flash predates the cutoff and remains tracked by `#911`, so it should not be duplicated.
