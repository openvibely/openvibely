Dependency licenses and source

Ubuntu dependency source is hosted by Ubuntu at:
https://launchpad.net/ubuntu/+source

Each image contains links to the exact Ubuntu source package versions it uses.
To print those links, replace IMAGE with the image tag or digest you downloaded:

  docker run --rm --entrypoint cat IMAGE /usr/share/licenses/openvibely-computer/ubuntu-sources.tsv

Follow each link to its source package downloads (.dsc, original source archives,
and Debian/Ubuntu packaging or patches). Full directions and dependency notices
are under /usr/share/licenses/openvibely-computer/ in the image.

For source requests or unavailable downloads, contact admin@openvibely.ai with
the image tag or digest and package version. The image includes SOURCE-OFFER.txt.
