# Community palette themes

The palette themes in `internal/themes/palettes.go` reuse a small set of anchor
colors from the projects below. OpenVibely derives every other color role from
those anchors; no theme files are copied. All listed projects are MIT licensed.

|---|---|---|
| Catppuccin Mocha, Catppuccin Latte | https://github.com/catppuccin/catppuccin | MIT, Copyright (c) 2021 Catppuccin |
| Tokyo Night | https://github.com/enkia/tokyo-night-vscode-theme | MIT, Copyright (c) 2018-present Enkia |
| Nord | https://github.com/nordtheme/nord | MIT, Copyright (c) 2016-present Sven Greb |
| Dracula | https://github.com/dracula/dracula-theme | MIT, Copyright (c) 2016 Dracula Theme |
